Конфиденциальность

Драйвер не собирает личные данные, ничего не отправляет в интернет и не хранит копии того, что вы печатаете.

  • Страницы обрабатываются в памяти и отправляются только на ваш принтер по USB.
  • В драйвере нет сетевого кода: никакой аналитики, рекламы, слежки и проверки обновлений.
  • Короткие технические сообщения (число страниц, ошибки) попадают в системный журнал печати Mac. Шаги установки записываются в /Library/Logs/m125-pclms-install.log. Оба журнала остаются на этом Mac.
  • Пароль нужен только для установки драйвера и добавления принтера.
  • Print with HP M125r может один раз спросить разрешение использовать Pages, Numbers, Keynote или Microsoft Word. Программа только открывает перетащенный документ и сохраняет временный PDF, который остаётся на этом Mac и удаляется после печати.

Что будет установлено

  • Драйвер — в папку /Library/Printers/m125-pclms
  • Четыре небольшие программы в Программы → Printer Driver for HP M125r: Print with HP M125r (печать перетаскиванием), Print two-sided with HP M125r (двусторонняя печать), Set Up Printer (настроить принтер) и Uninstall (удалить)

«HP» и «LaserJet» — товарные знаки HP Inc.; они используются только для названия поддерживаемого принтера.
