Done!

If the printer was connected and switched on, it is ready. Open any document, choose File → Print and select HP LaserJet Pro MFP M125r.

Drag and drop

Drop any file onto Applications → HP M125r Driver → Print with HP M125r to print it: PDF, photos, text, and Pages, Word, Numbers, Excel, Keynote or PowerPoint documents. Tip: drag that app to your Dock and then drop files on its icon. The first time, macOS asks whether the app may use Pages (or Word) to make a PDF. Click OK.

Two-sided printing

Drop a file onto Print two-sided with HP M125r. It prints the front sides, then shows how to put the paper back (printed side down) and prints the back sides. Try it with a 2–3 page document first.

Printer not in the list?

  1. Connect the USB cable and switch the printer on.
  2. Open Applications → HP M125r Driver → Set Up Printer.
  3. Follow the instructions. It can also print a test page.

To remove the driver later, open Applications → HP M125r Driver → Uninstall.
