Privacy

The driver collects no personal data, sends nothing over the internet and keeps no copies of what you print.

  • Your pages are converted in memory and sent only to your printer over USB.
  • There is no network code: no analytics, ads, tracking or update checks.
  • Short technical messages (page count, errors) go to the Mac's own printing log. Install steps go to /Library/Logs/m125-pclms-install.log. Both stay on this Mac.
  • Your password is used only to install the driver and add the printer.
  • Print with HP M125r may ask once to use Pages, Numbers, Keynote or Microsoft Word. It only opens the document you dropped there and saves a temporary PDF, which stays on this Mac and is deleted after printing.

What gets installed

  • The driver, in /Library/Printers/m125-pclms
  • Four small apps in Applications → HP M125r Driver: Print with HP M125r (drag-and-drop printing), Print two-sided with HP M125r, Set Up Printer and Uninstall
